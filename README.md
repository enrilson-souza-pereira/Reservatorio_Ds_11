# Reservatorio_Ds_11
# Monitor de Nível do Reservatório

Este é um script simples em **Python** que simula o monitoramento do nível de um reservatório. Ele gera um valor aleatório de 1 a 5 e exibe no terminal uma tabela colorida indicando a situação atual, utilizando a biblioteca `colorama`.

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* [Colorama](https://pypi.org/project/colorama/)

## 📋 Pré-requisitos

Certifique-se de ter o Python instalado e instale a dependência necessária:

```bash
pip install colorama
